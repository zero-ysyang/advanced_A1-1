# 🗂️ 나만의 프롬프트 관리 시스템

AI 작업에 자주 사용하는 프롬프트를 저장하고 관리하는 CLI 기반 애플리케이션입니다.

---

## 📌 주요 기능

| 기능 | 설명 |
|------|------|
| 프롬프트 추가 | 제목, 내용, 카테고리를 입력하여 새 프롬프트 저장 |
| 프롬프트 목록 | 저장된 전체 프롬프트를 번호 순으로 조회 |
| 카테고리별 조회 | 선택한 카테고리의 프롬프트만 필터링하여 조회 |
| 프롬프트 검색 | 제목 또는 내용에 포함된 키워드로 검색 |
| 프롬프트 상세 보기 | 번호 입력으로 특정 프롬프트의 전체 내용 확인 |
| 즐겨찾기 관리 | 자주 사용하는 프롬프트를 즐겨찾기(⭐)로 등록 |
| 즐겨찾기 목록 | 즐겨찾기로 등록된 프롬프트만 모아서 조회 |

---

## 🗂️ 지원 카테고리

- 텍스트 생성
- 이미지 생성
- 영상 생성
- 페르소나
- 자동화
- 기타

---

## 💻 실행 환경

- Python 3.8 이상
- 별도 패키지 설치 불필요 (표준 라이브러리만 사용)

---

## 🚀 실행 방법

### 1. 저장소 클론
```bash
git clone <repository-url>
cd prompt-manager
```

### 2. 프로그램 실행
```bash
python main.py
```

---

## 📖 사용 방법

프로그램 실행 후 메뉴 번호를 입력하여 기능을 선택합니다.

```
=== 나만의 프롬프트 관리 ===
1. 프롬프트 추가
2. 프롬프트 목록
3. 카테고리별 조회
4. 프롬프트 검색
5. 프롬프트 상세 보기
6. 즐겨찾기 관리
7. 즐겨찾기 목록
0. 종료
선택: 
```

### 프롬프트 추가 예시
```
선택: 1

=== 프롬프트 추가 ===
제목: 이메일 작성 도우미
내용: 당신은 전문 이메일 작성자입니다...

카테고리 선택:
1) 텍스트 생성
2) 이미지 생성
3) 영상 생성
4) 페르소나
5) 자동화
6) 기타
선택: 1

프롬프트가 추가되었습니다!
```

### 프롬프트 목록 예시
```
선택: 2

=== 프롬프트 목록 ===
1. [텍스트 생성] 회의록 요약 도우미
2. [이미지 생성] 브랜드 이미지 생성 ⭐
3. [이미지 생성] 스토리보드 씬 이미지 생성
4. [페르소나] 광고기획자 페르소나

총 4개의 프롬프트
```

## ⚠️ 현재 버전 제한 사항

- 프로그램 종료 시 추가/수정된 데이터는 저장되지 않습니다.
- 즐겨찾기는 추가만 가능하며 해제 기능은 지원하지 않습니다.
