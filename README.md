## 📌 주요 기능 설명

| 기능 | 함수 | 설명 |
|------|------|------|
| 프롬프트 추가 | add_prompt() | 제목, 내용, 카테고리를 입력하여 새 프롬프트 저장 |
| 프롬프트 목록 | show_prompt_list() | 저장된 전체 프롬프트를 번호 순으로 조회 |
| 카테고리별 조회 | show_prompts_by_category() | 선택한 카테고리의 프롬프트만 필터링하여 조회 |
| 프롬프트 검색 | search_prompt() |  제목 또는 내용에 포함된 키워드로 검색 |
| 프롬프트 상세 보기 | show_prompt_detail() |  번호 입력으로 특정 프롬프트의 전체 내용 확인 |
| 즐겨찾기 관리 | manage_favorites() |  자주 사용하는 프롬프트를 즐겨찾기(⭐) 등록/해제 |
| 즐겨찾기 목록 | show_favorite_list() |  즐겨찾기로 등록된 프롬프트만 모아서 조회 |


## 🗂️ 프롬프트 카테고리 설명

| 카테고리 | 설명 |
|------|------|
| 텍스트 생성 | 문서 초안, 요약, 번역, 검토 등 언어 작업 중심 |
| 이미지 생성 | 상품 사진, 배경, 라이프스타일 이미지 등 시각 자료 제작 |
| 영상 생성 | 장면 전개, 카메라 움직임, 스타일, 분위기를 담은 영상 구성 |
| 페르소나 |	특정 역할이나 전문가 관점으로 응답의 어조와 논리 조정 |
| 자동화 | 반복 업무를 구조화해 조사, 정리, 초안 작성, 검토 흐름 개선 |
| 기타 | 아이디어 발상, 데이터 분석, 코드 작성, 학습 보조 등 확장 활용 |

## 📖 사용 방법

프로그램 실행 후 메뉴 번호를 입력하여 기능을 선택합니다.

```
=== 나만의 프롬프트 관리 ===
1. 프롬프트 추가
2. 프롬프트 목록
3. 카테고리별 조회
4. 프롬프트 검색
5. 프롬프트 상세 보기
6. 즐겨찾기 관리
7. 즐겨찾기 목록
0. 종료
선택: 
```

### 1. 프롬프트 추가
```
선택: 1

=== 프롬프트 추가 ===
제목: 이메일 작성 도우미
내용: 당신은 전문 이메일 작성자입니다...

카테고리 선택:
1) 텍스트 생성
2) 이미지 생성
3) 영상 생성
4) 페르소나
5) 자동화
6) 기타
선택: 1

프롬프트가 추가되었습니다!
```

### 2. 프롬프트 목록
```
선택: 2

=== 프롬프트 목록 ===
1. [텍스트 생성] 회의록 요약 도우미
2. [이미지 생성] 브랜드 이미지 생성 ⭐
3. [이미지 생성] 스토리보드 씬 이미지 생성
4. [페르소나] 광고기획자 페르소나
5. [텍스트 생성] 이메일 작성 도우미

총 5개의 프롬프트
```

### 3. 카테고리별 조회
```
선택: 3

=== 카테고리별 조회 ===
1) 텍스트 생성
2) 이미지 생성
3) 영상 생성
4) 페르소나
5) 자동화
6) 기타
선택: 1

[텍스트 생성] 카테고리 프롬프트:
1. 회의록 요약 도우미
2. 이메일 작성 도우미

총 2개의 프롬프트
```

### 4. 프롬프트 검색
```
선택: 4

=== 프롬프트 검색 ===
검색어: 이미지

검색 결과:
1. [이미지 생성] 브랜드 이미지 생성 ⭐
2. [이미지 생성] 스토리보드 씬 이미지 생성

2개의 프롬프트를 찾았습니다.
```

### 5. 프롬프트 상세 보기
```
선택: 5

=== 프롬프트 상세 보기 ===
번호 입력: 1

────────────────────────────
제목: 회의록 요약 도우미
카테고리: 텍스트 생성
즐겨찾기: 
────────────────────────────
내용:
당신은 전문 비서이자 프로젝트 매니저입니다...
────────────────────────────
```

### 6. 즐겨찾기 관리
```
선택: 6

=== 즐겨찾기 관리 ===
프롬프트 번호 입력: 1
'회의록 요약 도우미' 프롬프트를 즐겨찾기에 추가했습니다!
```

### 7. 즐겨찾기 목록
```
선택: 7

=== 즐겨찾기 목록 ===
1. [텍스트 생성] 회의록 요약 도우미 ⭐
2. [이미지 생성] 브랜드 이미지 생성 ⭐

총 2개의 즐겨찾기
```
