# 🗂️ 나만의 프롬프트 관리 시스템

AI 작업에 자주 사용하는 프롬프트를 저장하고 관리하는 CLI 기반 애플리케이션입니다.

---

## 📌 주요 기능

| 기능 | 설명 |
|------|------|
| 프롬프트 추가 | 제목, 내용, 카테고리를 입력하여 새 프롬프트 저장 |
| 프롬프트 목록 | 저장된 전체 프롬프트를 번호 순으로 조회 |
| 카테고리별 조회 | 선택한 카테고리의 프롬프트만 필터링하여 조회 |
| 프롬프트 검색 | 제목 또는 내용에 포함된 키워드로 검색 |
| 프롬프트 상세 보기 | 번호 입력으로 특정 프롬프트의 전체 내용 확인 |
| 즐겨찾기 관리 | 자주 사용하는 프롬프트를 즐겨찾기(⭐) 등록/해제 |
| 즐겨찾기 목록 | 즐겨찾기로 등록된 프롬프트만 모아서 조회 |

---

## 💻 실행 환경

- Python 3.14 이상
- 별도 패키지 설치 불필요 (표준 라이브러리만 사용)

---

## 🚀 실행 방법

### 1. 저장소 클론
```bash
git clone https://github.com/zero-ysyang/advanced_A1-1.git
cd advanced_A1-1
```

### 2. 프로그램 실행
```bash
python prompt_manager.py
```

---

## 📖 사용 방법

프로그램 실행 후 메뉴 번호를 입력하여 기능을 선택합니다.

```
=== 나만의 프롬프트 관리 ===
1. 프롬프트 추가
2. 프롬프트 목록
3. 카테고리별 조회
4. 프롬프트 검색
5. 프롬프트 상세 보기
6. 즐겨찾기 관리
7. 즐겨찾기 목록
0. 종료
선택: 
```

### 1. 프롬프트 추가
```
선택: 1

=== 프롬프트 추가 ===
제목: 이메일 작성 도우미
내용: 당신은 전문 이메일 작성자입니다...

카테고리 선택:
1) 텍스트 생성
2) 이미지 생성
3) 영상 생성
4) 페르소나
5) 자동화
6) 기타
선택: 1

프롬프트가 추가되었습니다!
```

### 2. 프롬프트 목록
```
선택: 2

=== 프롬프트 목록 ===
1. [텍스트 생성] 회의록 요약 도우미
2. [이미지 생성] 브랜드 이미지 생성 ⭐
3. [이미지 생성] 스토리보드 씬 이미지 생성
4. [페르소나] 광고기획자 페르소나
5. [텍스트 생성] 이메일 작성 도우미

총 5개의 프롬프트
```

### 3. 카테고리별 조회
```
선택: 3

=== 카테고리별 조회 ===
1) 텍스트 생성
2) 이미지 생성
3) 영상 생성
4) 페르소나
5) 자동화
6) 기타
선택: 1

[텍스트 생성] 카테고리 프롬프트:
1. 회의록 요약 도우미
2. 이메일 작성 도우미

총 2개의 프롬프트
```

### 4. 프롬프트 검색
```
선택: 4

=== 프롬프트 검색 ===
검색어: 이미지

검색 결과:
1. [이미지 생성] 브랜드 이미지 생성 ⭐
2. [이미지 생성] 스토리보드 씬 이미지 생성

2개의 프롬프트를 찾았습니다.
```

### 5. 프롬프트 상세 보기
```
선택: 5

=== 프롬프트 상세 보기 ===
번호 입력: 1

────────────────────────────
제목: 회의록 요약 도우미
카테고리: 텍스트 생성
즐겨찾기: 
────────────────────────────
내용:
당신은 전문 비서이자 프로젝트 매니저입니다...
────────────────────────────
```

### 6. 즐겨찾기 관리
```
선택: 6

=== 즐겨찾기 관리 ===
프롬프트 번호 입력: 1
'회의록 요약 도우미' 프롬프트를 즐겨찾기에 추가했습니다!
```

### 7. 즐겨찾기 목록
```
선택: 7

=== 즐겨찾기 목록 ===
1. [텍스트 생성] 회의록 요약 도우미 ⭐
2. [이미지 생성] 브랜드 이미지 생성 ⭐

총 2개의 즐겨찾기
```
